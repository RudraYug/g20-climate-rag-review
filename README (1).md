# G20 Climate-Policy Evidence RAG — GitHub-Ready Review Repository

## Purpose

This repository accompanies an anonymised manuscript on **evidence retrieval, cited synthesis and human-supervised gap screening**. The heatmap is a first-pass screening aid, not a validated autonomous G20 policy classifier.

## Important status notes

- The 80-question set is author-prepared, non-adjudicated and single-reviewer-audited; it is not a gold standard.
- Formal heatmap agreement metrics cover 8 of 119 cells.
- Original and D6-audited heatmap versions are both preserved.
- Claim labels were generated by GPT-4o-mini against author-prepared evidence packages; they are automated estimates.
- Raw paired generation outputs and raw one-row-per-claim labels were not found in the supplied files and were not reconstructed.
