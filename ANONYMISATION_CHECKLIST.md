# Anonymisation Checklist for Peer Review

- [ ] Use the anonymised workbook copies in this package, not the identifiable originals.
- [ ] Confirm no reviewer or author name appears in visible cells, comments, hidden sheets or file properties.
- [ ] Remove ORCID, email, affiliation and personal repository account details from the review version.
- [ ] Ensure the repository URL or owner name does not reveal the author.
- [ ] Remove Git commit names/emails or publish a clean review snapshot without history.
- [ ] Do not include a non-anonymised `CITATION.cff` during double-blind review.
- [ ] Keep the original identifiable files in a separate private archive for post-acceptance release where consent permits.
- [ ] Review source excerpts for accidental personal data or confidential notes.
